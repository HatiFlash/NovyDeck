# NovyDeck 0.12.0 — Google Home block controls

## English

- **Google Home state in macro blocks.** In Workshop, select a Google Home control action block. Its properties offer **On**, **Off** and **Toggle** for the action's state at press time. Existing brightness settings and unconfigured blocks are not silently changed; brightness remains configurable in the plugin inspector.
- **Group selection stays in the plugin inspector.** From the block properties, open **Plugin settings → Control → Group** to select devices. The block properties show the number of selected devices. Settings are saved per block; changing the state does not discard the group's targets.
- **Plugins are separate.** OLED Saver and SignalRGB are not installed automatically by updating NovyDeck. Install or update the compatible plugin separately when needed; availability depends on the plugin and its requirements.

The UI checks use an offline Google Home test fixture, not an installed plugin or a live account. No Google Home device, physical deck, OLED display or SignalRGB hardware effect has been verified by these checks. Preparing this version does not publish an installer, plugin package or store listing, or install anything on the user's PC.

## Français

- **État Google Home dans les blocs de macro.** Dans l'Atelier, sélectionnez un bloc d'action de commande Google Home. Ses propriétés proposent **Allumer**, **Éteindre** et **Basculer** pour l'état à l'appui. Les réglages de luminosité existants et les blocs non configurés ne sont pas changés silencieusement ; la luminosité reste à régler dans l'inspecteur du plugin.
- **Choix du groupe dans l'inspecteur du plugin.** Depuis les propriétés du bloc, ouvrez **Réglages du plugin → Commander → Groupe** pour choisir les appareils. Les propriétés indiquent le nombre d'appareils du groupe. Les réglages sont enregistrés par bloc ; changer l'état ne supprime pas les cibles du groupe.
- **Plugins séparés.** Économiseur OLED et SignalRGB ne sont pas installés automatiquement lors de la mise à jour de NovyDeck. Installez ou mettez à jour le plugin compatible séparément si nécessaire, selon sa disponibilité et ses prérequis.

Les contrôles d'interface utilisent un plugin Google Home témoin hors ligne, pas un plugin installé ni un compte réel. Aucun effet sur un appareil Google Home, un deck physique, un écran OLED ou du matériel SignalRGB n'est vérifié par ces contrôles. Préparer cette version ne publie ni installateur, ni archive de plugin, ni référencement dans le magasin, et n'installe rien sur le PC de l'utilisateur.
