# NovyDeck 0.14.0 — Workshop editing and clearer updates

## English

- **Workshop drag-and-drop:** drag handles make block movement explicit. Drag blocks to reorder or nest them in branches; hold Ctrl while dragging to duplicate. Press Esc to cancel. Undo and Redo cover edits, and dragging near a panel edge autoscrolls. The Properties panel presents the selected block's editable settings.
- **What's new and update progress:** refreshed release cards make the available changes easier to review. Download/install progress is indeterminate when no reliable numeric progress is available; no invented percentage is shown.
- **Assistant plugin clarification:** the local assistant can use actions described by installed plugin manifests. This is not universal comprehension: it cannot infer undocumented plugin behavior or settings, and suggestions still need review and confirmation.

## Français

- **Glisser-déposer dans l'Atelier :** des poignées rendent le déplacement des blocs explicite. Faites glisser les blocs pour les réordonner ou les imbriquer dans les branches ; maintenez Ctrl pendant le glissement pour dupliquer. Échap annule l'opération. Annuler et Rétablir couvrent les modifications, et le défilement automatique suit le glissement près du bord d'un panneau. Le panneau Propriétés présente les réglages modifiables du bloc sélectionné.
- **Quoi de neuf et progression des mises à jour :** les cartes des nouveautés ont été actualisées pour faciliter la relecture des changements disponibles. La progression du téléchargement et de l'installation reste indéterminée lorsqu'aucune valeur numérique fiable n'est disponible ; aucun pourcentage n'est inventé.
- **Précision sur les plugins de l'assistant :** l'assistant local peut utiliser les actions décrites dans les manifestes des plugins installés. Cela ne signifie pas qu'il comprend tous les plugins : il ne peut pas déduire les comportements ou réglages non documentés, et ses propositions doivent toujours être relues et confirmées.

## Qualification

The English and French README sections include actual off-screen Windows-lab captures generated for 0.14.0. Automated UI gestures and the Windows CI passed before publication; these are not tests on Hatim's PC, a physical D6, a real third-party plugin installation/account, or an installed local AI model. Profiles and media are preserved by the existing updater; plugin packages are updated separately.

Les sections anglaise et française des README comprennent de vraies captures hors écran du laboratoire Windows générées pour 0.14.0. Les gestes UI automatisés et la CI Windows ont été testés avant publication ; il ne s'agit pas d'essais sur le PC de Hatim, un D6 physique, une installation ou un compte de plugin tiers réel, ni un modèle IA local installé. Le mécanisme existant de mise à jour préserve les profils et les médias ; les paquets de plugins se mettent à jour séparément.
